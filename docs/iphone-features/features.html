LaTeX Squiggly for iPhone

Every feature, in one place
Version 1.0 · updated 21 October 2026

A keyboard that types like the iPhone's own, turns LaTeX into symbols as you type, and makes equations into images you can paste anywhere. It comes with an app that teaches it, renders equations, and holds its settings.

The keyboard: maths as you type

LaTeX to symbols on space

Type \alpha then space and get α. About 200 commands: Greek letters, operators, relations, arrows, set symbols and more, from the same engine as the Mac app. Braced scripts convert too: x^{2} becomes x², a_{n} becomes aₙ.

See each conversion, and undo it NEW

The bar shows \alpha → α for a moment after space converts it, with an Undo button. Delete straight after does the same. With key taps on, a conversion taps a little firmer than a key.

Command suggestions

Type \ and a few letters and the bar offers matching commands with the symbol each makes, common ones first. Tap one to finish it. Structures like \frac and \sqrt come with empty boxes to fill in.

Your own shortcuts NEW

Make commands of your own in Settings, like \R for ℝ or \eps for ε. They convert on space, with the same undo, and come first in the suggestions. One with a built-in command's name takes its place.

Quick keys in the bar

$…$, { }, x², x₂ and a⁄b, each with the cursor already in the box. Space steps out of a box, and from the top of a fraction to the bottom.

Live equation preview

The bar typesets the maths before the cursor as you type it. Maths that won't typeset says why, such as an unknown command.

The symbols page

Thirty Greek letters and symbols one tap away, from the α∞ key, set in Latin Modern, LaTeX's own typeface NEW. Hold a key for its relatives: π for ϖ and Π, ≤ for ≪ and ⊆. A faint dot marks keys that have them NEW.

Converting on or off

The LS mark at the left of the bar: orange converts, dark keeps everything as typed, for LaTeX documents. Maths between $ signs always stays LaTeX, ready to copy as an image.

The keyboard: everyday typing

Feels like the iPhone's keyboard

  • Key sizes and pop-ups measured from Apple's keyboard
  • A touch between keys types the likelier letter
  • Fast two-thumb typing keeps its order
  • Slide from 123 onto a key to type it and go back
  • Keyboard clicks, and optional haptics

Spelling suggestions

Spellings and completions from the iPhone's dictionary, and your text replacements, in the bar. Nothing is ever changed unless you tap it, so maths and commands are left alone. Punctuation after a picked word takes back its space.

Gestures

  • Hold space to move the cursor like a trackpad
  • Hold delete to repeat, then delete whole words
  • Hold a letter for accents
  • Shift once for a capital, twice for caps lock
  • Two quick spaces type a full stop

Fits the text box

  • Email and web boxes get @, / and . beside space
  • Number boxes open on the numbers
  • Return says go, search, send, next or done, as the app asks
  • Automatic capitals, if turned on

Emoji page

A full emoji keyboard inside this one, by category, with the ones you use most first.

Light and fast NEW

A key press redraws only the keys that change, and word suggestions and fonts load without holding up typing. A letter takes about a third less time to go in, and the longest pauses are gone.

Equations as images

Copy from the bar

Type maths between $ signs, or select some, and tap Copy. Then paste the image into any app. Tap the preview first to see it large and pick small, medium or large, on a light or dark card.

Share sheet

Select LaTeX anywhere, such as a note, an email or a web page, tap Share, then LaTeX Squiggly. Copy, share or save the image from there.

Messages app

Write an equation in the Messages app drawer and send it as a picture. Recent equations stay there to send again.

The Render tab

For long or tricky equations: type or paste LaTeX, choose the size and card, then Copy or Share. Text with $…$ in it keeps its words around the maths.

The app

The website's look NEW

Each tab opens on an orange band with a wavy edge, its title in Bricolage Grotesque and the mascot sitting on the wave, over dotted cream paper. Orange section labels, outlined secondary buttons, and the same in dark mode.

Guide

Ten short lessons, about three minutes in all, from turning the keyboard on to images from anywhere, each ticked off as it is done. A one-minute tour on first launch.

Help

Answers to common questions, the four ways to make an image, tips and tricks for every key, and every symbol with a search; tap one to copy its command. At the bottom, links to the Chrome extension, the Mac and Windows apps, the website and GitHub NEW.

Settings

  • Spelling suggestions, on by default
  • Space space for a full stop, on by default
  • Automatic capitals, off by default
  • Haptics, off by default
  • Your shortcuts NEW
  • Links to the Chrome extension, the Mac and Windows apps, the website and the source code on GitHub NEW

iPad NEW

Runs on iPad, with the iPad's own keyboard layout: a row of numbers on top with their symbols over them, tab, caps lock, return and both shifts, and a key to hide the keyboard. The symbols page fits more maths, like ∑, ∀ and ∃. The keyboard stays the same height upright and sideways, and the app's screens keep a comfortable reading width. In Slide Over the keyboard takes an iPhone's layout.

Privacy

Nothing you type leaves your phone. Allow Full Access is recommended, and is used only to put images on the clipboard, read the app's settings and play haptics. Without it, everything else still works.

Needs iOS 16 or later, on iPhone or iPad. This page lists what the app does today; it is updated with each new feature.
