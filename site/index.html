Staying quiet

The hard part isn't converting. It's knowing when not to.

In a TeX editor, \alpha has to stay \alpha. So LaTeX Squiggly watches which app is in front, and in an editor it does nothing at all. It doesn't even keep a buffer there, so it can't replace anything.

These ship excluded, and the list is checked again at every launch, so an editor you install next month is covered too. Anything you remove stays removed.

Two consequences are built in. Safari's slow lookup is skipped inside the keystroke itself, where 109 ms would feel like a stuck key. And a browser that says nothing at all is treated as quiet, a setting you can turn off if you never open Overleaf.

The dollar rule

It knows maths from money

A bare x^2 can't convert on its own, or 2^3 in a sentence and a_b in a variable name would rewrite themselves. So scripts need $x^2$, which nobody types by accident.

And I have $5$ left isn't maths, so a span only converts when it holds a backslash, a caret or an underscore. Money has none of those, so it's left alone.

48 characters at most

A stray dollar earlier in the sentence can't reach forward and swallow half a line.

Always reported

Dollars mean you wanted maths, so if they can't convert, the app says so.

What it costs you

Nothing you can measure

Measured on the running Mac app over five idle minutes, with the energy metric Activity Monitor uses. macOS calls an app an energy problem at around 150 idle wakeups a second.

Nothing stored or sent

A short buffer of what you just typed lives in memory, and is dropped the moment a command completes or you move the caret, switch app or change tab. There is no network code.

Two permissions, and why

Input Monitoring to notice a command; Accessibility to replace it. With only the first, it could watch you type and do nothing about it.

Reads a page only while on

It looks into a browser's page only while conversion is on. Switched off, every app looks like a non-browser.

Nothing you type leaves your device

You should be careful with any app that can see your keystrokes. LaTeX Squiggly holds the last 64 characters in memory only long enough to spot a command, then forgets them. There is no networking code in the project at all, and nothing is written to disk except your settings.

You don't have to take that on trust: read the privacy policy, or the source code. Installed it? The guide walks you through the first steps.

Build it yourself Mac and Windows, from source

Both platforms run the same engine. The Windows tables are generated from the ones the Mac uses, and the two are checked against each other over 2,030 LaTeX fragments before anything is published, down to the number of backspaces. The Windows README says exactly what differs and why.

On a Mac

An app built on the Mac it runs on is never downloaded, so Gatekeeper never blocks it. You need Apple's Command Line Tools, not all of Xcode.

# 1. Apple's command line tools (not Xcode)
xcode-select --install

# 2. get the source
git clone https://github.com/SuperWalrus01/LaTeX-Squiggly.git
cd LaTeX-Squiggly

# 3. a stable signing identity, once, BEFORE the first install
scripts/setup-mac-signing.sh

# 4. build and install
scripts/install-mac-app.sh
open "/Applications/LaTeX Squiggly.app"

Order matters: macOS ties the Accessibility permission to the code signature, so signing after granting it undoes the grant. To see what the app currently sees:

"/Applications/LaTeX Squiggly.app/Contents/MacOS/LaTeX Squiggly" --diagnose

The Windows app

Built from a Mac or Linux machine: the .NET SDK cross-compiles. The script checks the port against the Mac engine's answers and publishes nothing if they disagree.

# needs the .NET 8 SDK; nothing else
scripts/build-windows.sh
