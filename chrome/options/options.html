LaTeX Squiggly

Type LaTeX in any text box and it becomes Unicode when you press space.

Welcome. Here is what LaTeX Squiggly does with your typing.

  • To recognise a command like \alpha, it keeps the last few characters you typed in a text box, in memory only. They are forgotten when you click, press an arrow key or change fields.
  • When you press space after a command, it replaces the command with the character, right where you typed it. Undo brings the command back.
  • Nothing you type is saved or sent anywhere. The extension makes no network requests.
  • It stays off on Overleaf and the other sites listed below, and in code editors.

Try it: type \alpha and a space in any text box on a web page. Pages that were already open need reloading first. Privacy policy

General

Sites where it stays off

In LaTeX source, \alpha has to stay \alpha. A site here covers its subdomains too, so overleaf.com includes www.overleaf.com. Code editors on any site are always left alone.

    Symbols

    Commands convert when you press space after them. Scripts go inside dollars: $x^2$ gives x², $a_1$ gives a₁. Fractions, roots and \mathbb{R} work too.

    Everything happens on this computer. LaTeX Squiggly keeps only the last few characters you typed, in memory, to recognise a command. It never stores or sends what you type, and these settings sync only through your own Chrome account. Privacy policy
