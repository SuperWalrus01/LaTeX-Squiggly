# Conformance

The reference every port of the engine is checked against.

| File | What it is |
|---|---|
| `reference.json` | 2,030 LaTeX fragments and the Swift engine's answer to each: the conversion result, and what the app would do if the fragment were typed and followed by a space. Generated by `scripts/generate-conformance-reference.py`. |
| `windows-result.json` | The summary the Windows runner writes after a passing run. The website quotes its numbers. |

The fragments cover every symbol, every script character, every refusal
message, every case that must stay silent, and the shapes that have caused bugs
before. Each port replays all of them and must give the identical answer, down
to how many characters to delete:

```
dotnet run --project windows/LaTeXSquiggly.Conformance -- conformance/reference.json
node chrome/test/conformance.mjs
```

Both files are generated. Never edit them by hand: change the engine or the
corpus in the generator, then regenerate. See
[docs/architecture.md](../docs/architecture.md).
